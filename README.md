# vedaantk.github.io

My portfolio site: **<https://vedaantk.github.io>**

Plain HTML, CSS and JavaScript on GitHub Pages, with a retro arcade theme. The ball
in the header is a working Breakout game.

What's on it:
- **Projects:** short write-ups with links to the live demos and code.
- **NBA predictor dashboard** ([`nba-predictor/`](nba-predictor/)): the live front end for
  [nbapred](https://github.com/VedaantK/nbapred).
- **Crossy Road clone** ([`crossy-road/`](crossy-road/)): a browser game made for a class.
- **Chat widget** ([`chat.js`](chat.js)): talks to a FastAPI + OpenAI backend on Render
  that answers questions in my voice.

Built with Claude as a coding assistant. The prompt history is in [`Prompts.txt`](Prompts.txt).
